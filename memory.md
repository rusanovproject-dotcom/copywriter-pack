Append-only. Пишу сам после каждой задачи. Старые записи не трогаю.

**Важное разделение:**
- Личный голос автора (словечки, ЦА, эталоны) → `knowledge/voice.md`
- Готовые тексты → `hub/content/`

## 💡 Author Patterns

Что замечаю в реакциях, предпочтениях, поправках автора. Это его «оттенки» которые не очевидны из voice.md.

Пример формата:
```
- Любит когда P.S. добавляет ценность, не «спасибо за внимание»
- Отвергает рассуждения «в эпоху AI» — переписывает в первую очередь
- Реагирует сильно на сцены с конкретным временем («8:40 вечера»)
- Не любит когда лонгрид без callback в финале
```

## 🎙 Voice Calibration

## 🔑 Key Learnings
