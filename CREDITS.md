# Credits & Attribution — Copywriter pack

Copywriter-агент использует материалы 2 внешних проектов напрямую (код/структура)
и синтезирует методологию из публичных книг, статей и исследований (не код —
атрибуция ниже даёт прозрачность источников, а не юридическое требование).

## Прямые заимствования (MIT License)

### 1. jalaalrd/anti-ai-slop-writing → knowledge/anti-slop-playbook.md (слой 1)

**Источник:** [github.com/jalaalrd/anti-ai-slop-writing](https://github.com/jalaalrd/anti-ai-slop-writing) (MIT License)

**Что взято:** каркас структурных паттернов AI-слопа — правило троек, ровные
предложения, рубленый паратаксис, качели хеджирования, корпоративный задор,
одинаковые абзацы, буллеты вместо предложений, пассив, переход-бантик в конце
каждого абзаца.

**Как адаптировано:** список портирован под русский язык — английские тики
(«delve», «tapestry») заменены на русские структурные признаки; добавлен
слой 2 (RU-канцелярит по Главреду/Ильяхову) и слой 3 (критерий Willison «след
кураторского усилия»), которых в оригинале нет.

**Куда положено:** `knowledge/anti-slop-playbook.md` (слой 1) — читает скилл `anti-slop`.

### 2. artemnovitckii/content-skills → knowledge/voice-learning-method.md

**Источник:** [github.com/artemnovitckii/content-skills](https://github.com/artemnovitckii/content-skills) (MIT License)

**Что взято:** архитектурный принцип voice-dna — «~20 постов автора → анализ
по осям → переиспользуемый профиль голоса», разделение «извлечение ДНК голоса»
и «письмо этим голосом» на два разных шага.

**Как адаптировано:** расширено до 6 осей анализа (архитектура предложений,
словарь, ритм и паузы, личностные маркеры, структурные привычки, анти-паттерны),
добавлены лимиты имитации из академических исследований (см. ниже) и формат
«5 секций + камертон ≤5 цитат» вместо произвольного дампа примеров.

**Куда положено:** `knowledge/voice-learning-method.md` — читает скилл `voice-learning`.

## Методологические источники (синтез, не код)

Остальная база знаний — это синтез публичных методологий копирайтинга и
маркетинга, а не копирование кода. Ключевые источники по файлам:

| Знание | Откуда синтезировано |
|--------|----------------------|
| `craft.md` — awareness-диагностика | Eugene Schwartz, «Breakthrough Advertising» (стадии осведомлённости, sophistication рынка) |
| `craft.md` — 6 типов лидов | Jon Bond, Gregory Kimble — «Great Leads» |
| `craft.md` — LF8 крючки | Drew Eric Whitman — «Cashvertising» |
| `craft.md` — 3 правила аргумента | Harry Dry (Marketing Examples) |
| `craft.md` — ритм и связность | Joseph Sugarman («Triggers»/связность предложений); монтажный принцип из практики видеоблогинга (смена плана) |
| `craft.md` — reason-why | Claude Hopkins, «Scientific Advertising» |
| `craft.md` — хук-паттерны | David Ogilvy (правило 5x), Justin Welsh (3-строчная модель треда) |
| `craft.md` — Five-Second Moment | Matthew Dicks, «Storyworthy» |
| `anti-slop-playbook.md` — слой 2 (RU-канцелярит) | Максим Ильяхов, «Пиши, сокращай» / методология Главреда |
| `anti-slop-playbook.md` — слой 3 | Simon Willison, эссе «Slop» (2024) — критерий «след кураторского усилия» |
| `craft-rubric.md` — evidence-grounding | принцип verdict-with-citation из исследований LLM-as-judge (обязательная цитата при вердикте) |
| `leads-matrix.md` — цикл evaluator-optimizer | Anthropic, «Building Effective Agents» (паттерн generator-critic) + Self-Refine (arXiv 2303.17651) + PerFine (arXiv 2510.24469) |
| `voice-learning-method.md` — лимиты имитации few-shot | академическое исследование по few-shot style transfer (лимит ~5 примеров, слабость на неформальных жанрах, частичная детектируемость клона) |
| `platforms.md` | публичная статистика площадок (Buffer, Meta/Threads, редакционная аналитика длинных площадок) — датировано, при устаревании сверяться с актуальными цифрами |

Эти источники — общедоступные книги, эссе и исследования; синтез их идей в
рабочие чек-листы не требует атрибуции по лицензии, но указан здесь для
прозрачности и как справочник для дальнейшего углубления.
