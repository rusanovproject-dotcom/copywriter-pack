# Smart Rewrite — докрутка смыслами и жирностью

Берёт готовый черновик и добавляет мяса. Это «нажми двоечку — докрути» в воркфлоу копирайтера.

**Когда:** черновик готов, добавить смыслов/жирности. **НЕ этот скилл:** другой регистр → `/style-switch` · другой угол подачи → `/angle-shift` · AI-паттерны → `/stop-slop` · написать с нуля → базовый воркфлоу копирайтера.

**Что читать:** `copywriter/core.md` (9 заповедей, особенно 2, 5, 8) · `knowledge/voice.md` секция «Аудитория» (аватар — Линза 1) + `hub/marketing/audience.md` если Маркетолог в офисе · `knowledge/voice.md` (что «жирно» по голосу автора — Линза 2) · `knowledge/anti-patterns.md` (стиль автора ≠ слоп).

## 5 линз

### 1. Аватар-чек (НЕ дословно)

Бьёт ли в боль реального аватара. ПОНИМАТЬ боль, а не вставлять цитаты механически.

**Сигналы:** абзац про «вообще проблему» а не про конкретного аватара · глагол не из мира аватара (предприниматель не «задумывается», он «считает кэш») · боль из чужого сегмента · цитата из анкеты вставлена куском.

**До → После:**
- ДО: «Многие предприниматели сталкиваются с нехваткой времени»
- ПОСЛЕ: «Машина по зарабатыванию денег работает на тебе. Утром снова открываешь календарь — там опять чужие задачи.»

### 2. Жирность подачи

Эмоциональная, цепляющая, живая. Жирность глагола, конкретика реакции, живость сцены.

**Эталон жирности:**
- ДО: «Диму начал беспокоить дорогая реклама»
- ПОСЛЕ: «Дима охренел от того, что у него подписчик по 300 рублей»

Если правка не звучит как этот эталон — недокрутил.

**Шаблонные глаголы → жирные:** беспокоить → охренел / завис / поплыл · задумываться → встал колом / забуксовал · решил → психанул / сорвался / махнул рукой · понял → дошло / огрёб · столкнулся → влетел / врезался.

**Сигналы мёртвой сцены:** нет конкретики реакции (где сидел, что перед глазами, что сказал вслух) · существительные вместо глаголов («произошло принятие решения») · абстракция там, где нужна деталь.

> **Граница:** жирность подачи у каждого автора своя — смотри `voice.md` секции «Голос» и «Стоп-фразы». Если в `overrides.md` запрещён мат / разговорная речь / агрессивная лексика — подбирай жирные глаголы в его рамке.

### 3. Глубина идеи + момент озарения

Есть ли точка где читатель скажет «бл*, не думал об этом»? Каждое предложение даёт инсайт или это информация? ЗАЧЕМ раскрыт раньше чем ЧТО?

**Сигналы:** каждый абзац без сдвига перспективы · ни одной фразы которую захочется сохранить · «что произошло» без «почему это меняет всё» · информация ради информации.

**До → После:**
- ДО: «Нейросети помогают копирайтерам быстрее писать тексты»
- ПОСЛЕ: «AI не ускорил работу — он показал, сколько в ней было моего страха»

### 4. Обогащение (центральная)

Что **добавить** (метафора · цифра/факт/исследование · отсылка к личности типа Маска/Хормози/Карпатого · цитата · историческая параллель · новостная привязка) · **вырезать** (балласт, повторы, абстракции) · **заменить**.

**Опция веб-поиска.** Если нужны факты/цитаты которых нет в контексте — предложи: «Хочешь, параллельно схожу в веб — найду конкретные факты/цитаты, что вставить? Я пока перепишу, потом покажу — выберешь.» Запуск через `WebSearch`/`WebFetch` параллельно с переписыванием в одном сообщении.

### 5. Сегментация ценности

Один аватар или несколько? Если несколько — где выгода каждого, на ИХ языке?

**Сигналы:** «для всех» = ни для кого · общая выгода без «как это работает для предпринимателя vs эксперта vs фрилансера» · аватар не назван.

**До → После:**
- ДО: «Эта система помогает быть продуктивным»
- ПОСЛЕ: «Собственнику с командой — снимет микро-менеджмент. Эксперту-одиночке — даст ритм. Фрилансеру — соберёт хаос проектов в один поток.»

## Формат вывода — A+B

### Часть A — Анализ + правки (всегда)

```markdown
# /smart-rewrite: [название]

## По линзам — где слабо
1. Аватар-чек: [места + почему мимо + какой сегмент должен быть]
2. Жирность: [шаблонные глаголы → жирные альтернативы, привязка к строкам]
3. Глубина: [где плоско + какой сдвиг рамки даст инсайт]
4. Обогащение: [ВСТАВИТЬ метафору/цифру/отсылку в блок X · ВЫРЕЗАТЬ Y · опционально ВЕБ-ПОИСК по Z]
5. Сегментация: [для кого реально работает, где сегментировать]

## Переписанные блоки (copy-paste ready)
[Готовые фрагменты с пометкой какой блок заменяют. Где нужны факты автора —
TODO с привязкой к вопросу из Части B.]
```

### Часть B — Финал, максимум 3 вопроса

Только факты/конкретика из жизни автора, которых Claude не может знать.

**МОЖНО:** реальный кейс с именем · точная цифра проекта · знакомый из ситуации · пример из практики последнего месяца.

**НЕЛЬЗЯ:** «что чувствуешь?» · «какую эмоцию хочешь донести?» · «какой тон ближе?» · «как видишь текст?». Эмоции и тон скилл предлагает сам в линзах 2-3.

Меньше точных вопросов лучше больше размытых. Если 3 нет — задавай 1.

В конце меню:
```
1) Применить правки автоматом — переписываю целиком (плейсхолдеры на твоих местах)
2) Пройти со мной по [N] вопросам — соберём конкретику и докрутим точнее
3) Сначала веб-поиск по [тема] — найду факты, потом докрутим
```

## Пример

**Input:** «AI меняет работу копирайтера. Многие задумываются как использовать нейросети. Я провёл много времени и понял что промпт — это важно.»

**Output (сжато):**
- 1: сегмент не назван (новичок? эксперт?) → выбрать
- 2: «задумываются → упёрлись», «провёл много времени → угробил N часов», «понял → дошло»
- 3: ноль инсайтов → сдвиг рамки (плохой промпт = диагностика твоего непонимания задачи)
- 4: ВСТАВИТЬ отсылку (Карпатый: «prompting is the new programming»), метафору («промпт = техзадание самому себе») · ВЫРЕЗАТЬ «есть несколько важных принципов» · веб-поиск по цитатам Карпатого?
- 5: для новичка один угол, для эксперта другой

**Часть B:** (1) Сколько часов на нейросети за год — точно? (2) Один кейс где промпт показал что ТЫ не понимал задачу — сцена. (3) Пост для новичка или эксперта?

## Антипаттерны

1. Не хвалить — задача найти где недокручено
2. Каждая претензия = конкретный кусок + конкретная замена (не абстрактно)
3. Только факты автора в вопросах — не эмоции/тон
4. Не переписывать молча — сначала линзы, потом блоки
5. Стиль автора (из `voice.md`) ≠ слоп (мат, фрагментация, разговорность — это голос; см. `knowledge/anti-patterns.md`). Сегмент непонятен → спрашивай, не выдумывай
