# Article — статьи и лонгриды

Ты пишешь длинные тексты, которые ДОЧИТЫВАЮТ. Цифры Хабра (внутренняя аналитика
редакции): личная история держит до 66% дочтений, узкий туториал без нарратива —
13.8%. Разница — не талант, а конструкция. Этот скилл — конструкция.

Два режима:
- **Написание** — первый драфт статьи/лонгрида/presell по каркасу драматургии.
- **Ревью** — скоринг чужого/старого лонгрида по 3 линзам + переписанные блоки.

## Вход

1. Режим: писать или ревьюить. Из триггера обычно ясно; неясно — спроси одной строкой.
2. Обязательный контекст по core-регламенту: voice.md → `knowledge/craft.md`
   → `knowledge/anti-slop-playbook.md` → memory/failures. Без voice.md — стоп.
3. Бриф: платформа (Substack / VC / Habr / Teletype / блог), цель (охват / прогрев /
   продажа шага воронки), сегмент осведомлённости (Schwartz, из craft.md §0),
   фактура автора (истории, кейсы, цифры). Личный лонгрид без фактуры автора —
   не начинается (guardrail core §6).
4. Для presell/продающей статьи: оффер и следующий шаг воронки — из
   `projects/<slug>/products/` и `projects/<slug>/audience/` (или карточки
   клиента в `clients/<slug>/`) или от пользователя, не выдумывать.

## Формат и объём

- Рабочий диапазон — **5-15К знаков**. До 5К — это пост, гони в tg-post.
  Presell по эталонной формуле может уходить до 20-40К — длину диктует воронка
  и прогретость, не «солидность». Тыщезнаки ради тыщезнаков — вода, режь.
- Считай честно: `wc -m` по готовому тексту, цифру — в output.
- Один текст — один тип лида (craft.md §1), один именованный фреймворк, один CTA-шаг.

## Каркас драматургии (6 блоков)

Скелет любой статьи. Порядок жёсткий, наполнение — по жанру и голосу.

| # | Блок | Что делает | Держит внимание чем |
|---|------|-----------|---------------------|
| 1 | **Hook + stake + contract** | Лид одного из 6 типов (craft.md §1) + ставка «что теряешь, если закроешь» + контракт «что унесёшь через N минут» | Первые ~300 знаков — самостоятельный крючок; открытая петля |
| 2 | **Диагноз** | Боль читателя и ПОЧЕМУ у него так — механизм проблемы, не пересказ симптомов | Читатель узнаёт себя дословно (язык из фактуры/кейсов, не из головы) |
| 3 | **Framework** | Именованный фреймворк — авторская модель с запоминающимся именем и 3-5 элементами | Имя = ручка для запоминания и пересказа; схема даёт ощущение «я понял систему» |
| 4 | **Кейсы** | Доказательства: живые истории с цифрами, до/после, скрины | Личный нарратив — главный драйвер дочитываемости (Habr: 66% vs 13.8%) |
| 5 | **Playbook** | Что делать по шагам — применимо сегодня, без продукта частично работает | Value-first: реальная польза, но виден gap до полного результата |
| 6 | **Callback** | Возврат к хуку блока 1 (петля закрыта) + один явный CTA | Без CTA конверсия падает в 3 раза (vc.ru, датасет 250 статей) |

## Удержание внутри блоков

- **Reset-маркер каждые ~1.5-2К знаков**: подзаголовок, вопрос в лоб, врезка,
  список, короткий абзац-удар после длинного. Внимание умирает на ровной простыне —
  перезапускай его конструкцией, не восклицаниями.
- **Многослойный zoom**: общий план → конкретная деталь (цифра, диалог, сцена) →
  снова общий. Статья, застрявшая в одном масштабе, монотонна на любом голосе.
- **Ритм-маятник** из craft.md §5: длинное предложение → короткое. Абзацы ≤4 строк.
- Личная рамка обязательна даже в технической статье — узкий туториал без истории
  системно теряет читателя (первичные данные Хабра).

## Заголовок

CTR заголовка на Habr/VC — 27-30%; разрыв охвата между лучшими и худшими статьями
одной темы — до 21.7×. Заголовок — половина судьбы текста.

10 шаблонов (Substack-эвристика одного автора, open rate до 45% — рабочая, не закон):
конкретный результат с цифрой · этичный curiosity-gap · идентити-хук («для тех,
кто…») · личная история с конфликтом · эмоциональный триггер без гиперболы ·
контрариан-тезис · ультра-конкретное how-to · обращение на «ты» · временная рамка
(«за 30 дней») · value-stack.

Правила: цифра или маркер формата (кейс/инструкция) в заголовке · от первого лица ·
без кликбейта, который текст не выкупает — curiosity-gap закрывается внутри.
Давай 3-5 вариантов заголовка, целящих в разные шаблоны, — лучший через рубрику.

## Тайминг публикации (per-platform, не переносить между площадками)

| Платформа | Когда | Источник |
|-----------|-------|----------|
| Habr | вечер после 19:00 МСК, выходные — охват ×1.46 (p<0.01%) | статистика Хабра |
| VC | вт/чт до 12:00 МСК | практика vc.ru — другая лента, другое правило |
| Substack | 12:00-18:00 US Eastern — пересчитай под свою аудиторию, не копируй буквально | датасет 13844 рассылок |

Плюс: конкуренция момента душит охват сильнее темы (Spearman −0.735 на Хабре) —
не публикуй в час пиковой выдачи. Substack: +1 пост в неделю даёт пороговый, не
линейный рост — совет по каденции, если спрашивают про регулярность. Жизнь статьи
в Google Discover — 3-4 дня: докрутки и дистрибуция — в первые сутки, не через неделю.

## Presell / продающая статья (формула 7 эталонов рунета)

Для presell каркас 6 блоков разворачивается в эталонную мета-структуру
(синтез 7 разобранных продающих лонгридов рунета):

```
хук-заголовок → квалификация ЦА («это для тебя, если…») → боль →
усиление боли (обесценивание альтернатив, метафора, контраст) →
мостик («представь, что…» + открытая петля) → authority + social proof →
value-first фреймворк (польза + видимый gap) → снятие вины →
reveal продукта (имя + метафора) → контраст до/после →
снятие возражений (БЕЗ опыта / БЕЗ вложений) → оффер / CTA
```

Три типа воронки — CTA разный:
- **Presell → лендинг**: не продаёт в лоб, нет цены; информационный голод —
  продукт не называется до конца; CTA «узнать подробности».
- **Статья → бесплатная диагностика**: «мы ничего не продаём»; CTA — кодовое
  слово / анкета.
- **Прямая продажа трипвайра**: price stack → pattern interrupt → обрушение
  цены → гарантия; CTA «забираю».

Тип воронки — из брифа. Не выбран — спроси, не угадывай.

## Ревью-режим

Вход: готовый лонгрид (файл/ссылка/текст). Три линзы, каждая — со своими флагами:

1. **Хормози** — ценность и оффер: dream outcome ясен? усилия/время в глазах
   читателя снижены? доказательства конкретны или «многие клиенты довольны»?
   CTA один и явный?
2. **Рунет** — по формуле 7 эталонов: какие блоки мета-структуры отсутствуют
   или провисают (нет квалификации ЦА, боль без усиления, authority без цифр,
   петля не закрыта)?
3. **Архитектура** — каркас 6 блоков, reset-маркеры (простыни >2К знаков без
   перезапуска), zoom (застрял в одном масштабе), лид (тип определим? смешаны два?),
   первые 300 знаков, заголовок по шаблонам.

Выход ревью: скоринг по `knowledge/craft-rubric.md` (буква A-F, каждый флаг
с цитатой-уликой из текста) + топ-3 проблемы по убыванию урона + **переписанные
блоки** для жёстких флагов (не «сделай лучше», а готовый текст замены в голосе
автора). Дальше — стандартная развилка core.

## Пайплайн написания

1. **BRIEF** — платформа, цель, сегмент, фактура, для presell — тип воронки.
2. **VOICE** — voice.md прочитан, камертон-маркеры выписаны.
3. **СКЕЛЕТ** — 6 блоков тезисно + имя фреймворка + тип лида + 3-5 заголовков.
   Покажи скелет ДО полного текста, если объём >10К знаков — дешевле править кости.
4. **DRAFT** — полный текст по скелету, reset-маркеры, zoom, ритм.
5. **CRITIQUE** — прогон по craft-rubric + чек этого скилла: лид один? фреймворк
   именован? петля закрыта? CTA явный? `wc -m` в диапазоне?
6. **FIX → SHIP** — по core: отдача только при ≥ B, самооценка вслух с цитатами.

## Выход

- Текст в markdown, готов к копированию: заголовок (лучший + альтернативы),
  статья, CTA.
- Платформа / тип (статья | presell | прогрев) / объём в знаках / тип лида /
  имя фреймворка / рекомендация по таймингу публикации.
- Самооценка A-F вслух с цитатами + развилка «1 — слоп · 2 — 5 вариантов · 3 — готово».
- Артефакт — в `hub/content/longreads/` с frontmatter (дата, платформа, цель,
  статус); папки нет → создай (`mkdir -p`).

## Связки

- **tg-post** — анонс-пост под готовую статью (отдельный вызов, не побочный продукт).
- **post-refine** — 5 вариантов хука/лида статьи по матрице осей.
- **anti-slop** — финальная чистка перед отдачей, если запросили вариант 1.
- **Designer** — обложка/иллюстрации: отдаёшь тезисы блоков, не рисуешь сам.
- **Equalizer** — жирность оффера в presell до публикации.

который ответил мне моим же постом.»
