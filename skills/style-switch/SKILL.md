# `/style-switch` — переписать в другом регистре

Готовый текст + другой регистр поверх того же `voice.md` = тот же смысл, другая упаковка.

---

## Что на выходе

Либо **один новый текст** (если выбран один регистр), либо **2-3 варианта одного и того же текста в разных регистрах** (если пользователь хочет сравнить).

После — снова развилка 1-5.

---

## Логика (4 шага)

### Шаг 1 — Просканируй регистры

Найди все файлы `knowledge/voice-*.md` рядом с `voice.md` (НЕ `voice.md.template`, НЕ сам `voice.md`).

```bash
ls knowledge/voice-*.md | grep -v 'voice.md.template$'
```

В пакете 5 стартовых: `voice-universal.md`, `voice-provocative.md`, `voice-expert.md`, `voice-longread.md`, `voice-storyteller.md`. Автор мог добавить свои через `/voice-dna --extension <name>` — они тоже здесь.

Прочитай **frontmatter каждого**: `style_name` + `mode`. Это твой каталог.

### Шаг 2 — Предложи варианты под тему текста

Не вываливай весь список. Посмотри **тему и тип** текущего текста, выбери **2-3 подходящих** регистра. Например:

- Текст = жёсткий разбор провала клиента → подходят `expert` (приговор) и `provocative` (без цензуры)
- Текст = pre-sell под услугу с историей клиента → подходит `storyteller`
- Текст = длинная методичка → `longread`

**Эталон реплики:**

> *«Окей, текст про [тема] — могу переписать в:*
> *— **[название регистра 1]** ([mode]) — [одна фраза почему подходит]*
> *— **[название регистра 2]** ([mode]) — [одна фраза почему]*
> *— **[название регистра 3]** ([mode]) — [одна фраза почему]*
>
> *Какой? Или скажи "сразу несколько" — переплавлю в каждом, сравнишь.»*

### Шаг 3 — Дождись выбор

- **Один регистр** (цифра / имя) → перепиши один раз
- **«сразу несколько» / «все три» / «сравни»** → перепиши **в каждом из предложенных**, отдай блоком с разделителями
- **Имя которого нет в предложенных, но есть в папке** → бери его (пользователь знает что хочет)

### Шаг 4 — Перепиши

Для каждого выбранного регистра:
1. Прочитай файл регистра целиком (`knowledge/voice-<name>.md`)
2. Возьми **голос** из `voice.md` (личные словечки, ЦА, эталоны)
3. Наложи **дельты** регистра (ритм / лексика / структурные привычки / финал)
4. Перепиши текст: тот же смысл, та же длина (±20%), но **в новой упаковке**
5. Не теряй конкретику и цифры из оригинала

**Если несколько регистров** — каждая версия отдельным блоком:

```
---
**Регистр: [Название 1]**

[Текст в регистре 1]

---
**Регистр: [Название 2]**

[Текст в регистре 2]

---
```

В конце — **одна строка** «что отличается» по каждой паре (например: «Эксперт жёстче, концовка-приговор; Сторител мягче, через героя»).

После — снова спроси развилку 1-5.

---

## Anti-patterns — так делать НЕЛЬЗЯ

🚨 **Не вываливай список всех 5 регистров.** Фильтр под тему — макс 3 варианта. Иначе пользователь утонет в выборе.

🚨 **Не игнорируй регистры собранные автором.** Если в папке лежит `voice-luxury.md` — он наравне со стартовыми.

🚨 **Не меняй смысл, угол или длину текста.** Это не `/smart-rewrite` (докрутка по смыслам) и не `/angle-shift` (другой угол). Только упаковка.

🚨 **Не переписывай в регистре которого нет в папке.** Никаких «давай как у Хемингуэя» — только реальные `voice-*.md` файлы.

🚨 **Не забудь снова спросить развилку 1-5** после результата. Это правило копирайтера.

---

## Связки

- **← Копирайтер** — после готового текста пользователь жмёт «4» или просит «другой регистр»
- **↔ `/voice-dna --extension <name>`** — если пользователь хочет регистр которого нет в папке, направь сначала туда (автор соберёт свой за 5-15 минут)
- **→ Копирайтер** — после переписки снова развилка 1-5 (можно ещё раз сменить регистр / угол / докрутить)
