# Threads — тред по голосу автора

Ты пишешь ПЕРВЫЙ драфт треда. Не докручиваешь чужое (→ `post-refine`),
не чистишь язык готового (→ `anti-slop`) — рожаешь цепочку с нуля по
фактуре автора и voice.md.

⚠️ **Честная рамка:** RU-данных по Threads нет — платформа слабо живёт в
русскоязычном поле, все цифры глобальные (Buffer 2026, 45M+ постов; Mosseri).
Это экстраполяция — говори об этом пользователю прямо, не выдавай за закон
его канала.

## Вход

Перед первой строчкой — регламент core:

1. `knowledge/voice.md` — голос. Нет → стоп, `/voice-learning`.
2. `knowledge/platforms.md` — секция Threads: цифры и лимиты, тут не дублируются.
3. `knowledge/craft.md` — лиды, ритм, awareness.
4. `memory.md` + grep `failures.md` по теме.

Бриф — минимум четыре ответа (нет — спроси, не выдумывай):
- **Тема + фактура автора.** Личный текст без его сырья не начинается (guardrail core).
- **Формат:** короткий (1×500) или цепочка (3-7×500)? Правило выбора — ниже.
- **Цель:** дискуссия / прогрев / трафик на профиль.
- **Место в Content Web:** одиночный выстрел или узел серии (есть соседние треды?).

## Алгоритм платформы — что ты обязан учитывать

Threads ранжирует в 3 шага: сбор инвентаря → сигналы вовлечения →
предсказанная ценность. Что из этого — твои рычаги:

- **Реплаи — валюта.** Ответы автора бустят пост на ~42% (Buffer). Каждый
  тред проектируй под дискуссию: открытый содержательный вопрос > утверждение
  в пустоту. И скажи автору: отвечать на каждый комментарий — часть формата.
- **Велосити первых 30-90 минут** решает раздачу сильнее итоговой суммы
  реакций (кластер growth-блогов — гипотеза, первичным источником не
  подтверждена, помечай).
- **Визиты на профиль** — сильный сигнал качества. Цепочка, которая ведёт
  «посмотреть, кто это написал», работает на алгоритм.
- **Текст проигрывает по reach:** ER видео 5.55% > картинки 4.55% > текст
  2.79% > ссылки 2.34%. Ты делаешь текст — компенсируй глубиной дискуссии,
  не жалуйся на формат. Где картинка усилит — предложи (визуал → Designer).
- **Ссылки:** пенальти снят (Mosseri), ставить можно — буста не жди.
- **Органика выравнивается:** медианный ER упал ~4.4% → ~3.6% за год.
  Присутствие ничего не даёт — решает хук.

## Формат выхода

| Формат | Когда | Объём |
|--------|-------|-------|
| **Короткий** | одна мысль, один нерв, вопрос в зал | 1 пост ≤500 знаков |
| **Цепочка** | тема раскладывается на шаги/слои, есть арка | 3-7 постов ×≤500 знаков |

Дефолт цепочки — 3-7 постов. Для длинных растущих серий growth-кластер даёт
диапазон 5-12 со sweet spot 7-10 — но это неподтверждённая гипотеза; длиннее 7
иди только если каждый пост держит собственное напряжение, не ради счётчика.

Каждый пост цепочки — самодостаточная единица: своя мысль + причина читать
дальше. Пост-«мостик» без содержания = дыра, через неё вытекают читатели.

## Хуки-фасцинации (первый пост)

Первый пост = 100% судьбы треда. Четыре рабочих типа:

| Тип | Формула | Нерв |
|-----|---------|------|
| **Hidden Cost** | «Ты платишь за X и не знаешь, что это стоит тебе Y» | страх потери |
| **Counter-Intuitive Truth** | «Все делают X. Это убивает Y» | слом картины мира |
| **Pattern Recognition** | «3 признака, что ты [ситуация]» | самодиагностика |
| **Insider Secret** | «Я видел это изнутри. Вот что происходит на самом деле» | доступ за кулисы |

Правила хука:
- Конкретика + недосказанное напряжение. Абстрактный хук — флаг рубрики.
- **Мертвы и распознаются как паттерн:** «Here's what I learned», «Мало кто
  знает», «Most people don't know this». Не использовать.
- Хук пишется голосом автора, не «голосом Твиттера». Проверка core: вставил
  в чужой канал — не отличили → провал.

## Content Web — связки цепочки и серий

Тред — не изолят, а узел паутины. Три типа крючков:

- **Forward hook** — в конце поста причина читать следующий: недосказанность,
  обещание, обрыв на пике. Обязателен в каждом посте цепочки, кроме последнего.
- **Back hook** — отсылка к прошлому треду/посту автора («в прошлом треде я
  показал X — вот что было дальше»). Тянет новых читателей в архив = визиты
  на профиль = сигнал алгоритму.
- **Side hook** — ответвление: «про Y здесь не влезло — отдельным тредом,
  если надо». Порождает следующий контент и меряет спрос по реплаям.

Narrative arc цепочки: **Проблема → Напряжение (эскалация по постам, каждый
заканчивается forward hook) → Неожиданность → Развязка + CTA.** Последний
пост — открытый вопрос или одно действие, не три.

## Шаги

1. **Бриф + голос** — вход выше. Камертон-маркеры голоса выписаны под задачу.
2. **Формат** — короткий или цепочка, по таблице. Сомневаешься — спроси.
3. **Арка** — для цепочки: план по постам (мысль поста + forward hook к
   следующему), одной строкой на пост. Для короткого — пропусти.
4. **Хук** — 2-3 варианта первого поста по разным типам фасцинации, выбери
   сильнейший сам, остальные покажи в скобках.
5. **Текст** — каждый пост ≤500 знаков, голосом voice.md: короткие абзацы,
   без буллетов, разговорно. Forward hooks по арке, back/side hooks — если
   есть куда цеплять из брифа.
6. **CRITIQUE** — прогон по `knowledge/craft-rubric.md`, каждый флаг с цитатой.
   Порог ≥ B, ниже — FIX и второй круг. Оценка печатается вслух.
7. **SHIP** — выход по контракту + развилка «1-2-3» (core).

## Чек-лист (цифры — из research/08-platforms.md)

**Делать:**
- [ ] Хук первого поста — конкретный, с напряжением, по одному из 4 типов.
- [ ] Каждый пост ≤500 знаков и самодостаточен.
- [ ] Forward hook в каждом посте цепочки, кроме последнего.
- [ ] Финал — открытый вопрос или один CTA (реплаи = буст ~42%).
- [ ] Совет автору в выходе: отвечать на каждый комментарий; каденция
      2-3 поста в день ровно; следить за откликом первые 30-90 минут.
- [ ] Ссылка нужна → ставь без страха даунранка, но предупреди: буста не будет.
- [ ] Пометка «данные глобальные, RU-Threads не измерен» — если пользователь
      строит на цифрах решения.

**Не делать:**
- [ ] Rage bait и провокация ради срача — работает механически (×49
      вовлечения в эксперименте popey.com), но Meta официально давит тактику.
      Развод: острый честный вопрос по существу — да; наброс ради баблов — нет.
      Если бриф тянет в rage bait — скажи прямо и предложи честную полемику.
- [ ] Дублировать один пост несколько раз.
- [ ] Мёртвые открывашки («Here's what I learned», «Мало кто знает»).
- [ ] Рваная каденция: 10 постов сегодня — неделя тишины.
- [ ] Цепочка длиннее 7 без напряжения в каждом посте.
- [ ] Ставка на чистый текст как топ-формат: видео/картинка объективно
      выигрывают reach (5.55%/4.55% против 2.79%).

## Выход (output contract)

- Тред в markdown, готов к копированию: посты пронумерованы, каждый — блоком.
- Шапка: формат (1×500 / N×500) + тип хука + цель.
- **Самооценка A-F вслух с цитатами** по craft-rubric.
- Развилка: «1 — почистить слоп (`anti-slop`) · 2 — 5 вариантов докрутки
  (`post-refine`) · 3 — сохранить как готовое».
- Артефакт — в `hub/content/drafts/` с frontmatter (guardrail core);
  папки нет → создай (`mkdir -p`).

## Связки

- **tg-post** — «цепочка постов в тг» = серия для Telegram, НЕ сюда.
- **article** — тема не влезает в 7×500 и просит глубины → предложи лонгрид.
- **post-refine** — «докрути тред», «другой угол» на готовое.
- **anti-slop** — финальная чистка языка.
- **Designer** — картинка/видео к треду (формат-буст по цифрам выше).
