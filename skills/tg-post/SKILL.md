# tg-post — пост для Telegram

Ты пишешь ПЕРВЫЙ драфт поста в ТГ. Не варианты (это `post-refine`), не чистку
(это `anti-slop`) — драфт с нуля по фактуре автора. Скилл — шаг DRAFT
пайплайна core: после него текст уходит в CRITIQUE по `knowledge/craft-rubric.md`.

## Вход (без этого не начинаешь)

1. **Голос-источник прочитан** — voice.md или пресет стиля по резолюции core
   (нет ни дефолта, ни voice.md → витрина `knowledge/styles/INDEX.md`, НЕ стоп).
   Выпиши под задачу: зачины автора (бери из голос-источника, не выдумывай
   свои), маркеры речи, как автор закрывает пост.
2. **Фактура автора** — голосовое, черновик, случай, цифры. Для личного блога
   без фактуры не пишешь (guardrail core №6): «дай сырьё — историю, цифру,
   что зацепило». Клиентский пост — по брифу.
3. **Сегмент аудитории** — холодная или тёплая (определяет длину, см. чек-лист).
   Непонятно из брифа → спроси одной строкой.
4. **Цель поста** — прогрев / польза / продажа / серия. Одна цель = один пост.
5. `knowledge/craft.md` §4-5 (хуки, ритм) + `knowledge/platforms.md` §Telegram —
   загружены.

## Шаги

### 1. Хук — отдельным под-шагом

Правило Ogilvy 5x: зачин читают в 5 раз чаще тела. Прогони **5 кандидатов
хука** до того, как писать текст — каждый через свой зачин из voice.md или
хук-паттерн из craft.md §4. Один Big Idea на пост: две мысли = ноль мыслей.

Первые **~300 знаков** — самостоятельный крючок: в ленте видны только они,
до «Показать полностью». Прочитай их отдельно от текста: тянут развернуть?
Не тянут — хук мёртв, меняй.

Первая строка = подтверждение обещания, не разгон. Никаких «но сначала
предыстория».

### 2. Тело — ритм и разметка

- **Маятник длины.** Короткое предложение. Потом длинное, которое разворачивает
  мысль. Три подряд одной длины — измеримый сигнал ИИ-текста, рубрика поймает.
- **Абзацы ≤3-4 строки**, пустая строка между ними — единственный надёжный
  разделитель ТГ.
- **Разделители-линии** («———», «•••») — максимум один на пост, только на
  смысловом переломе. Пост, нарезанный линиями через абзац, читается как
  лендинг, не как живой текст.
- **Скобки — второй удар** после хука: одни, с новой информацией (конкретика,
  снятие возражения). Больше одних — тик.
- **Эмодзи-дисциплина: 1-3 на пост**, только смысловые акценты. Эмодзи в начале
  каждой строки = разметка бота, не автора. Если voice.md даёт свои знаки
  (скобки-смайлы и т.п.) — они закон, поверх ничего не добавляй.
- **Смена плана** каждые 2-3 абзаца: факт → история → цифра → вопрос.
- Zero-Click: ценность внутри поста, не «по ссылке интересное».

### 3. CTA — мягкий, один, в конце

После ценности, не вместо неё. Одно действие: «сохрани», «напиши в комменты»,
«перейди». Два CTA = ноль CTA. Продающий пост — CTA обязателен; прогревочный —
можно закрыть фирменной концовкой автора из voice.md или открытым хвостом.

### 4. Серия (если просили серию / контент-план)

- Каждый пост серии самодостаточен: новый читатель входит с любого.
- **Открытый хвост** в конце каждого, кроме финального: недосказанность,
  обещание следующей части — конкретное («завтра покажу цифры»), не «продолжение
  следует».
- Разные зачины у соседних постов — два подряд одинаковых = паттерн, читатель
  распознаёт.
- Контент-план подавай таблицей: № / зачин / Big Idea / хвост.

### 5. Передай в CRITIQUE

Драфт готов → верни управление core: прогон self-check craft.md §7, оценка
по craft-rubric вслух, развилка «1 — слоп · 2 — 5 вариантов · 3 — готово».
Сам скилл оценку не печатает — не дублируй гейт.

## Чек-лист (цифры — жёсткие, прогоняй перед выдачей драфта)

| # | Проверка | Норма |
|---|----------|-------|
| 1 | Длина поста | **≤2000 знаков** — рабочая норма; техпотолок 4096 |
| 2 | Подпись к медиа | **≤1024 знака** — отдельный лимит, не путать с постом |
| 3 | Холодная аудитория | **≤500 знаков**, сильный зачин |
| 4 | Тёплая база | **1000-1800 знаков** с фактурой |
| 5 | Крючок-превью | первые **~300 знаков** работают сами по себе |
| 6 | Кандидатов хука прогнано | **5**, выбран один, Big Idea — одна |
| 7 | Абзацы | **≤3-4 строки**, пустые строки между ними |
| 8 | Эмодзи | **1-3 на пост**, не в каждой строке |
| 9 | Разделители-линии | **≤1 на пост** |
| 10 | Скобки-второй-удар | **максимум одни** |
| 11 | Ритм | нет **3 подряд** предложений одной длины |
| 12 | CTA | **один**, в конце, после ценности |
| 13 | Картинка (если есть) | **≤1MB**, стиль канала |
| 14 | Голос | зачин и концовка — из voice.md, тест «чужой канал» пройден |
| 15 | Слоп | текст сверен с `knowledge/anti-slop-playbook.md` (3 слоя) |

Длина — переменная под аудиторию, не догма: пользователь хочет «как лучше по
цифрам моего канала» → отправляй мерить TGStat/Telemetr, средние по рынку
за его правду не выдавай (platforms.md).

## Выход

- Текст поста в markdown, готов к копированию в ТГ.
- Строка-паспорт: `Telegram · {тип: пост/рассылка/серия N} · {знаков} ·
  сегмент {холодная/тёплая} · зачин {какой}`.
- Для серии — все посты + таблица контент-плана.
- Дальше — CRITIQUE в core (рубрика вслух + развилка).

## Связки

- **voice-learning** — нет voiceprint → сначала туда, ни строчки до.
- **post-refine** — пользователь просит варианты/другой угол готового драфта.
- **anti-slop** — вариант 1 развилки, финальная чистка языка.
- **article** — фактура тянет на 2000+ слов → предложи лонгрид, не дави пост.
- **threads** — просят цепочку для Threads/X → туда, механики другие.
- Артефакт — в `hub/content/` (drafts/posts) с frontmatter (guardrail core №4).

## Примеры (Input → Output)

**Input:** «Вот голосовое: клиент три месяца сидел на подрядчике за 80К,
мой бот закрыл то же за вечер. Напиши пост в тг.»
**Output:**
```
Голос загружен: voice.md. Фактура: кейс 80К/мес vs бот за вечер — есть цифры
и нерв. Сегмент: тёплая база → целюсь в 1000-1800 знаков.
Хук: прогнал 5 кандидатов, взял зачин «факт-крюк» — цифра 80К в первой строке.
[текст поста, 1420 знаков: крючок в первых 300, абзацы ≤4 строк, 2 эмодзи,
одни скобки после хука, CTA «напиши в комменты, что у тебя жрёт больше всего»]
Паспорт: Telegram · пост · 1420 зн. · тёплая · факт-крюк.
Дальше CRITIQUE по рубрике.
```

**Input:** «Нужна серия из 3 постов про запуск мастер-группы, к четвергу.»
**Output:**
```
Голос загружен: voice.md. Цель: прогрев → продажа. Серия — 3 поста, каждый
самодостаточен, у №1-2 открытый хвост, CTA-продажа только в №3.

| № | Зачин | Big Idea | Хвост |
|---|-------|----------|-------|
| 1 | личная история | почему я сам застрял без системы | «завтра — что изменило» |
| 2 | факт-крюк | механика: 1 час в день с ИИ | «в четверг открою двери» |
| 3 | вопрос подписчика | оффер МГ + условия | CTA: ссылка на оплату |

[три текста, каждый ≤2000 зн., зачины разные, ритм-маятник]
Паспорт: Telegram · серия 3 · 1650/1480/1890 зн. · тёплая.
Дальше CRITIQUE — рубрика по каждому посту отдельно.
```

**Input (анти-пример):** «Докрути вот этот пост, дай позлее.»
**Output:** не твоя зона — готовый текст крутит `post-refine` (ось «другой
угол»). Роутинг туда, драфт заново не пишешь.
