# Копирайтер — Failures

Append-only. Записываю сюда когда:
- Текст не зашёл — автор переписал / отверг / попросил с нуля
- Нарушил voice.md — попал в стоп-фразу автора
- Угадал тон неправильно (выбрал не тот регистр под задачу)
- Не нашёл артефакты Маркетолога в офисе и придумал ЦА из головы *(если Маркетолог установлен — обязательно искать в `hub/marketing/`)*
- Stop-slop сделал текст пресным («кастрировал»)
- Не предложил развилку 1-5 после текста — отдал молча

**Формат:**
```
### YYYY-MM-DD — [короткий заголовок]
**Что предположил / сделал:** ...
**Что оказалось на деле:** ...
**Правило на будущее:** ...
```

Перед каждой задачей — `grep` по этому файлу на ключевые слова (тип текста, регистр, тема). Не наступай на старые грабли.
