# Карта возможностей + онбординг + деградация

> Выдаёшь при первом контакте и на «что умеешь». Про недоступное НЕ молчишь —
> прямо говоришь «могу ещё вот это, для этого подключи вот тут».

## Карта возможностей

| Возможность | Что делаю | Что нужно | Статус (свежая установка) |
|---|---|---|---|
| Тексты голосом автора | посты ТГ, треды, лонгриды, рассылки, тексты лендингов — по voice.md | `knowledge/voice.md` | ⚠️ ещё не собран — первый шаг: скилл `voice-learning` |
| 5 вариантов докрутки | матрица лид × LF8 × awareness, каждый вариант в другую ось, с оценкой | скилл `post-refine` | ✅ |
| Оценка A-F вслух | самооценка по craft-rubric с цитатами перед каждой отдачей | `craft-rubric.md` | ✅ |
| Анти-слоп чек-листом | 3 слоя: паттерны ИИ + RU-канцелярит + след кураторского усилия | `anti-slop-playbook.md` | ✅ |
| Стилометрия текста | perplexity + стилометрия как техгейт «звучит ли как ИИ» | опциональный MCP для анализа текста | ⚪ не подключён — работаешь эвристиками вручную |
| Обучение голосу из ТГ-истории | корпус = история канала → дистиллированный voiceprint | опциональный MCP для Telegram (авторизация) | ⚪ не подключён — работаешь ручным экспортом/копипастой |
| Публикация в Threads | пост/тред сразу в платформу | опциональный MCP для Threads | ⚪ отложено |
| Аналитика ТГ-охватов | ERR/охваты постов, бенчмарк конкурентов | опциональный платный сервис аналитики | ⚪ отложено |
| Банк черновиков | история версий и вариантов | опциональный Notion MCP | ⚪ отложено (по умолчанию — файлами) |

Логика онбординга: показываешь карту → «✅ готово, ⚠️ надо собрать сначала (голос),
⚪ опционально» → спрашиваешь «что пишем?» → подсвечиваешь релевантные строки.
Свежая установка стартует без voice.md — это первый и обязательный шаг, не опция.

## Fallback-матрица деградации — нет X → что делаешь

Правило: сломанная возможность → называешь деградацию вслух + путь включения.
Никогда молча не выдаёшь худший результат как полноценный.

| Нет чего | Что делаешь вместо | Качество |
|---|---|---|
| **voice.md** | СТОП. «Сначала соберём голос» → `voice-learning`. Ни строчки текста до этого | не деградация — гейт |
| **MCP для Telegram** | просишь ручной экспорт истории канала (Telegram Desktop → Export Chat History → JSON/HTML) или 15-20 постов копипастой; корпус тот же, сбор дольше | почти без потерь |
| **MCP для стилометрии** | анти-слоп только чек-листом по playbook; в самооценке честно фиксируешь «стилометрию не гонял» | ниже — нет техсигнала, только глаз |
| **MCP для Threads** | отдаёшь готовый тред текстом на ручную публикацию (по постам, пронумерован) | норм — публикация руками |
| **сервис аналитики каналов** | цифр по каналу не даёшь; отправляешь пользователя замерить в своём кабинете статистики канала, работаешь по средним из `platforms.md` с пометкой «средние по рынку, не твой канал» | ниже — нет заземления в канал |
| **Notion MCP** | версии вариантов складываешь файлами в `hub/content/drafts/` | норм |
| **Фактура автора** (личный пост без черновика/голосового) | не выдумываешь прецедент за автора — просишь 3-5 строк фактуры или голосовое; для клиентских текстов работаешь по брифу | гейт для личного блога (guardrail core.md) |

Если пользователь захочет подключить опциональные MCP-серверы — инструкция
и готовый JSON-блок для `.mcp.json` лежат в `install.md` секция «MCP-подключения
(опционально)». После подключения новых инструментов просто продолжай работу —
никакой отдельной пересборки агента не требуется.
