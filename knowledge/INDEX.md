# Knowledge — карта файлов

База знаний копирайтера. Делится на 3 слоя: универсальное ядро (читается каждым письмом), личный голос автора (создаётся через `/voice-dna`), стартовые регистры-надстройки (общие для всех авторов).

## Что лежит сейчас

| Файл | Размер | Слой | Кто заполняет | Кто читает |
|------|--------|------|---------------|------------|
| `craft.md` | ~90 строк | универсальное ядро | приходит в пакете | копирайтер перед каждым текстом |
| `anti-patterns.md` | ~60 строк | универсальное ядро | приходит в пакете | копирайтер перед каждым текстом + при любой QA-проверке |
| `voice.md.template` | ~140 строк | шаблон | приходит в пакете | используется скиллом `/voice-dna` как заготовка |
| `voice.md` | ~150 строк | **личный голос автора** | собирается через `/voice-dna` из 5-15 текстов | копирайтер перед каждым текстом |
| `voice-universal.md` | ~140 строк | стартовый регистр (extension) | приходит в пакете | дефолт для постов / кейсов / продающих |
| `voice-provocative.md` | ~107 строк | стартовый регистр (extension) | приходит в пакете | сторителл-эссе на больших темах |
| `voice-expert.md` | ~116 строк | стартовый регистр (extension) | приходит в пакете | разоблачение мифов, жёсткая позиция |
| `voice-longread.md` | ~231 строка | стартовый регистр (extension) | приходит в пакете | pre-sell статьи / pillar-контент / методички 5-15К |
| `voice-storyteller.md` | ~184 строки | стартовый регистр (extension) | приходит в пакете | pre-sell посты-истории под услуги / консультации |

## Принцип «голос + регистр»

- **Личный голос** (`voice.md`) — фактура автора: словечки, ЦА, его эталоны, его стоп-фразы.
- **Регистр** (`voice-*.md`) — общая упаковка: ритм, лексика, структурные привычки этого тона.

При письме копирайтер берёт **голос** + накладывает один из **регистров** → персональный голос в выбранной упаковке.

## Когда какой регистр

| Тип задачи | По умолчанию |
|------------|--------------|
| Короткий пост ТГ, тред, рекламный креатив | `voice-universal.md` |
| Кейсы, отчёты, welcome-цепочки | `voice-universal.md` |
| Лонгрид 5-15К, pre-sell статья, pillar-контент | `voice-longread.md` |
| Эссе на большой теме (политика / культура / абсурд) | `voice-provocative.md` |
| Разоблачение мифа, жёсткая критика индустрии | `voice-expert.md` |
| Pre-sell пост-история про героя-зеркало (для услуг / консультаций / продуктов где есть «человек на приёме / в работе») | `voice-storyteller.md` |
| Лендинг | базовый Универсальный + ситуативно по теме |

Если пользователь жмёт «4 — перепиши в другом регистре» после готового текста — копирайтер запускает `/style-switch`, который сам сканирует папку `knowledge/voice-*.md` и предлагает 2-3 подходящих под тему. Может переписать сразу в нескольких регистрах для сравнения.

## Расширение автором

В версии 1.1.0 появится опция собрать свой регистр (например `voice-luxury.md` или `voice-corporate.md`). Файл будет попадать сюда же — копирайтер автоматически увидит его при следующей развилке-4. Сейчас (v1.0.0) — пользуйся пятью стартовыми регистрами.
