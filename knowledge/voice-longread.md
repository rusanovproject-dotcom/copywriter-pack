# Регистр — «Экспертный лонгрид»

> Стартовый регистр-надстройка. Накладывается **поверх** личного `voice.md` автора. Здесь только **дельты** — что устроено иначе, чем в Универсальном (`voice-universal.md`).
>
> **«Экспертный лонгрид»** — длинный продуманный разбор с архитектурой, многослойным zoom'ом и именованными фреймворками, который читатель может **унести как готовую методологию**. Тон Универсального + структура книжной главы + разговорные вставки чтобы не стать скучной лекцией. Используется для pre-sell статей, pillar-контента, методичек, тематических разборов на 5-15К знаков.

---

## Когда включаем

- Pre-sell статья перед запуском продукта
- Pillar-контент канала / блога / медиа
- Методичка / гайд / разбор фреймворка
- Тематический разбор — «всё что я знаю про X в одном месте»
- Любой текст 5-15К знаков, где простой пост не выдерживает темы

**Когда НЕ включаем:**
- Telegram-посты до 3К знаков (это Универсальный)
- Эссе на больших темах без структуры (это Разговорный)
- Разоблачение мифа в одном куске (это Прожжённый эксперт)

---

## Главный принцип регистра

**Лонгрид ≠ длинный пост.** Длинный пост — это пост, который надо было сократить. Лонгрид — это **архитектурное произведение**: с контрактом, многослойным zoom'ом, ресет-точками, callback'ами в финал. Если лонгрид можно сократить без потери — это плохой лонгрид (просто пост раздутый).

Главная задача автора в этом регистре — **держать внимание на 7-15 минут чтения**. Универсальный пост держит на 1-2 минуты, и там можно жить за счёт ритма + одной мысли. Лонгрид требует **инженерии внимания** — где будет пик, где валли, где reset, где payoff.

---

## 5 корневых принципов

**1. Контракт с читателем — в первой трети.**
В первые 300-500 слов читатель должен получить три вещи: **что** автор будет разбирать, **зачем** это ему лично нужно, и **что он унесёт** к концу. Без контракта читатель не вкладывается во время. Пример формы: *«Этот пост — не про "X в общем". Этот пост про конкретную проблему Y, и как с ней работать. К концу у тебя будет 1 фреймворк и 5 готовых правил, которые можно применить в понедельник.»*

**2. Многослойный zoom — от системы к тактике.**
В пост умещается 1 уровень глубины. В лонгрид — **3-4 уровня одновременно**:
- Философия / принцип («почему вообще»)
- Фреймворк / рамка («как это работает на схеме»)
- Кейс / история («вот реальный пример»)
- Тактика / playbook («что делать в понедельник»)

Лонгрид движется между этими уровнями, не задерживается долго на одном — иначе либо абстракция, либо инструкция. Идеальный ритм: спустился вниз → дал кейс → поднялся → дал принцип → опять вниз.

**3. Именованные фреймворки — то что унесут.**
Из лонгрида читатель должен вынести **1-2 названия которые запомнит**. Концепция с именем — это твой собственный язык, и он работает как маркер «я знаю это от автора X». Без названий лонгрид становится потоком советов, которые не складываются в башке.

**4. Conversational reset — каждые 1.5-2К знаков.**
Внимание падает естественно через 90-120 секунд чтения. Если не вернуть — читатель закрыл. Reset — это **разговорная вставка**, которая ломает плотность аналитики и возвращает живой голос. Это технический приём. Без него лонгрид превращается в Cosmopolitan-листицл или в скучную методичку.

**5. Architecture > listicle. Callback'и в финал.**
Простой нумерованный список из 7 правил — не лонгрид, это пост, замаскированный под лонгрид. Настоящая архитектура: **открытие → диагноз → рамка → 2-3 кейса → playbook → payoff с возвратом к открытию**. В финале обязательно **callback** к чему-то из первой части (фразе, кейсу, метафоре). Это закрывает кольцо и даёт читателю ощущение «автор знал куда ведёт».

## Архитектура идеального лонгрида (6 блоков)

### Блок 1 — HOOK + STAKE + CONTRACT (5-10% длины)

**Что:** провокационный заход + установка рамки + обещание payoff'а.
**Как:** хук (провокация / личное признание / цифра / сцена — как в Универсальном) → stake (*«Этот пост не про X. Он про Y, что важнее»*) → contract (*«К концу у тебя будет [то-то]. Прочитаешь за 8 минут.»*).
**Зачем:** даёт читателю причину остаться на 7+ минут.

### Блок 2 — ДИАГНОЗ (15-20%)

**Что:** описание текущей боли / распространённой ошибки / заблуждения рынка.
**Как:** карикатура распространённого подхода → *«я сам через это прошёл»* (самокомпрометация) → почему этот подход НЕ работает с конкретикой.
**Зачем:** читатель видит свою боль на странице. Узнаёт себя — значит вкладывается.

### Блок 3 — FRAMEWORK / РАМКА (15-20%)

**Что:** введение именованного концепта.
**Как:** дать название → объяснить через метафору (бытовую, как в Универсальном) → why this matters.
**Зачем:** читатель получает мыслительный инструмент. Это самое ценное в лонгриде.

### Блок 4 — МНОГОСЛОЙНЫЕ КЕЙСЫ (30-40%)

**Что:** 2-3 конкретных истории с цифрами и именами.
**Как:**
- Кейс 1 — про себя (личное)
- Кейс 2 — про знакомого / клиента (внешнее)
- Кейс 3 — гипотетический сценарий (применение)
- Между кейсами — conversational reset
- В каждом — ссылка на framework из блока 3

**Зачем:** абстракция превращается в конкретику. Читатель верит в фреймворк через примеры.

### Блок 5 — PLAYBOOK / ПРАКТИКА (15-20%)

**Что:** конкретные шаги к применению.
**Как:** *«С чего начать в понедельник»* — 3-7 шагов → подводные камни (*«где облажаешься»*) → опционально чеклист / формула / правило.
**Зачем:** даёт читателю выход в действие. Без playbook'а лонгрид «интересно почитать», но ничего не меняется.

### Блок 6 — PAYOFF + CALLBACK + (опц.) PRE-SELL (5-10%)

**Что:** синтез + возврат к открытию + опционально мягкий CTA.
**Как:** callback к фразе / кейсу / метафоре из блока 1 → однострочный синтез (афоризм-якорь) → опционально *«если хочешь как я — приходи туда-то»*.
**Зачем:** закрывает кольцо. Читатель уходит с ощущением целостности и с одной фразой в башке.

---

## Что добавляется относительно Универсального

- **Подзаголовки H2/H3** — каждые 500-800 слов. Без них лонгрид нечитаем
- **Жирные акценты** в важных строках (не всё подряд — точечно, 1-2 раза в блоке)
- **Блок-цитаты** для ключевых фраз / framework'ов
- **Перечисления с длинными буллетами** — 2-3 фразы в каждом, не одно слово
- **Формулы / схемы** в текстовом виде — *«X = Y \* Z»*, *«А → Б → В»*
- **Reset-маркеры** — больше чем в Универсальном, минимум 1 на 1500 знаков

Всё остальное (на «ты», скобочки `))` как маркер живости, мат лёгкий в кульминации, самоирония в скобках, цифры-якоря, метафоры из быта, опечатки точечно, гибрид я/мы) — наследуется из Универсального.

## Маркеры conversational reset (toolkit)

Когда плотность аналитики растёт — вставить одну из этих фраз, чтобы вернуть живой голос:

- *«Окей, выдохни.»*
- *«Знаю как это звучит.»*
- *«Стоп — я сейчас не про X говорю, я про Y.»*
- *«Поясню на пальцах.»*
- *«Сейчас будет грязный пример.»*
- *«Если ты сейчас думаешь "ну это не для меня" — погоди ещё минуту.»*
- *«Тут многие сворачиваются. Я бы тоже сворачивался. Но смотри что дальше.»*
- *«Окей, окей, давай ещё пример.»*
- *«Перечитай предыдущий абзац — это важно.»*
- *«Чёт я загнался. Откатываемся к началу.»*

---

## Toolkit named-приёмов

- **Якорь** — короткая запоминающаяся фраза-формула (3-7 слов). Якорь даётся 1-2 раза в лонгриде, потом callback в финал.
- **Карикатура** — гипертрофия подхода до абсурда, чтобы показать его неработоспособность (приём из «Прожжённого эксперта», но в лонгриде используется аккуратнее, без злости).
- **Грязный кейс** — реальная история с именами, цифрами, провалами. Например: *«Знакомый Х потратил Y на канал привлечения, и вот что пошло не так.»*
- **Формула** — структурный элемент *«X = Y \* Z»*. Запоминается лучше чем абзац.
- **Антипаттерн-якорь** — короткое описание «как нельзя», после которого даётся «как надо».
- **Callback** — отсылка в финале к фразе / метафоре / кейсу из открытия.
- **Сценка-диалог** — короткий обмен репликами вместо абстрактного описания.
- **Reset-вставка** — короткая разговорная фраза для возврата живого голоса (см. выше).

## Самопроверка перед публикацией

Если хоть один «нет» — это не лонгрид, это раздутый пост.

- [ ] **Контракт обозначен в первой трети?** Что разбираем + зачем + что унесёт.
- [ ] **Есть ли минимум 1 именованный framework?** Без него читатель ничего не унесёт.
- [ ] **Есть ли многослойный zoom?** Принцип + рамка + кейс + тактика — все четыре слоя присутствуют?
- [ ] **Есть ли минимум 2 reset-маркера на каждые 5К знаков?** Без них внимание падает.
- [ ] **Есть ли хотя бы 1 грязный кейс с именами и цифрами?**
- [ ] **Есть ли callback к открытию в финале?** Закрывает кольцо.
- [ ] **Есть ли playbook / 3-7 шагов «в понедельник»?** Без выхода в действие — лонгрид «интересно почитать», но не работает.
- [ ] **Лонгрид нельзя сократить без потери?** Если можно — это раздутый пост, не лонгрид.

## Шпаргалка — Универсальный vs Экспертный лонгрид

| | «Универсальный» (`voice-universal.md`) | «Экспертный лонгрид» |
|---|---|---|
| Длина | 1-3К знаков | 5-15К знаков |
| Структура | Хук → история → CTA | 6-блочная архитектура с подзаголовками |
| Глубина zoom'а | 1 уровень | 3-4 уровня одновременно |
| Frameworks | Опционально | Обязательно 1-2 названных |
| Подзаголовки | Нет / редко | Каждые 500-800 слов |
| Жирные акценты | Точечно | Регулярно, как анкеры |
| Reset-маркеры | Не нужны (короткий формат) | Каждые 1.5-2К знаков |
| Контракт с читателем | Не нужен | Обязателен в первой трети |
| Кейсы | 1 живой | 2-3 разной природы |
| Playbook | Опционально | Обязательно |
| Callback в финал | Опционально | Обязательно |
| Финал | CTA / реакции | Синтез + callback + опц. мягкий CTA |
