# Арсенал копирайтера

> «Под это есть приём». Смотришь сюда по запросу → подбираешь слой.
> Роутинг-триггеры — в core.md, здесь — карта «что даёт / когда».
> Слой: 🟢 база (всегда доступно) · 🟡 после подключения · ⚪ отложено/внешнее.

## Свои 6 скиллов (`.claude/skills/`)

| Скилл | Что даёт | Когда | Слой |
|---|---|---|---|
| `tg-post` | Пост ТГ ≤2000 зн. по voice.md: зачины, ритм-маятник, разметка, мягкий CTA, серии | Первый драфт поста/рассылки/серии для ТГ | 🟢 |
| `threads` | Тред: 1×500 или цепочка 3-7×500, хуки фасцинации, Content Web, narrative arc | Первый драфт под Threads/X | 🟢 |
| `article` | Лонгрид/статья/presell 2000-6000 слов: 6 блоков, zoom, reset-маркеры, именованный фреймворк + ревью-режим (3 линзы) | Первый драфт длинного текста · «проверь лонгрид» | 🟢 |
| `post-refine` | 5 вариантов по матрице осей (лид × LF8 × awareness, `leads-matrix.md`) + докрутка по смыслам + другой угол; evaluator-optimizer до ≥ B | Готовый текст → варианты/усиление; ветка «2» развилки | 🟢 |
| `anti-slop` | 3-слойная чистка языка по `anti-slop-playbook.md` + стилометрия-гейт (если MCP подключён); отдаёт diff «что вырезал и почему» | Финальная чистка; «звучит как ИИ»; ветка «1» развилки | 🟢 |
| `voice-learning` | Сборка/обновление voiceprint из корпуса (свой автор → `knowledge/voice.md` с одобрения; клиент → `clients/<slug>/brand/voice.md`) | Нет voice.md · «собери голос» · новый клиент | 🟢 |

Границы одной строкой: жанровые = ПЕРВЫЙ драфт · post-refine = ВАРИАНТЫ
готового · anti-slop = ЯЗЫК готового · voice-learning = не тексты, только голос.

## MCP (опциональные подключения)

Всё — не зависимость, а множитель силы. Инструкция подключения — `install.md`
секция «MCP-подключения (опционально)».

| MCP | Что даёт | Когда | Слой |
|---|---|---|---|
| MCP для анализа текста (readability + AI-детект) | Стилометрия и перплексия как техгейт анти-слопа | Внутри `anti-slop` перед выдачей | ⚪ не подключён по умолчанию |
| MCP для Telegram | Чтение истории канала (корпус для voice-learning) + публикация черновиков | Сборка голоса · черновик в канал | ⚪ не подключён по умолчанию |
| Notion MCP (remote) | Банк черновиков/версий, история вариантов | Архив итераций по запросу | ⚪ отложен |
| MCP для Threads | Публикация в Threads API | Постинг тредов без рук | ⚪ отложен (нужна верификация площадки) |
| Сервис аналитики каналов | RU-аналитика охватов/ERR постов и конкурентов | Замер «что заходит» по каналу | ⚪ отложен (обычно платный) |

Нет MCP → деградация по `capabilities-map.md`, молча не деградируешь.

## Внешние скиллы офиса (не твои, но по теме — если установлены)

Если в твоём офисе есть отдельные скиллы под соседние жанры/техники — зови их,
не изобретай заново внутри себя. Если их нет — работай своими средствами
(жанровыми скиллами + craft.md), просто честно скажи что делаешь это без
специализированного инструмента.

| Что нужно | Куда посмотреть | Когда зовёшь |
|---|---|---|
| Быстрый душевный пост-история без полного пайплайна | скилл под сторителлинг (если установлен) | Пользователь просит «как я рассказываю», исповедь |
| Жёсткая резка текста (kill your darlings) | скилл под редактуру объёма (если установлен) | Текст раздут, нужна хирургия объёма |
| Сторителлинг-механика (5-second moment, stakes) | скилл под драматургию истории (если установлен) | В тексте нужна история, а она не работает |
| Value Equation, оффер-механика | скилл под офферы (если установлен) | Офферный пост/CTA — не переизобретай equation внутри себя |
| Съём брифа под текст | скилл под интервью/бриф (если установлен) | Большая задача без внятного брифа |
