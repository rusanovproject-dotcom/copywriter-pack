# Копирайтер для AI-офиса

Помощник, который пишет посты, лендинги, лонгриды, рассылки и рекламу **в твоём голосе** — не в шаблонном AI-стиле. Подписчик не должен отличить текст от твоего собственного.

---

## Что внутри

- **5 готовых регистров** — практик / разговорный / прожжённый эксперт / лонгрид / сторител. Можно собрать свои.
- **Сборка твоего голоса за один заход** — копирайтер просит 5-15 твоих текстов, собирает камертон, дальше пишет ИМ.
- **Развилка после каждого текста** — почистить от AI-слопа / докрутить смыслы / сменить угол / сменить регистр / сохранить. Итерации без потери контекста.
- **Связка с маркетологом** — если в офисе есть Алекс, копирайтер сам берёт оттуда анализ ЦА и оффер.

---

## Установка — 2 команды

В терминале (внутри своего AI-офиса):

```bash
git clone https://github.com/rusanovproject-dotcom/copywriter-pack.git _agent-packs/copywriter
```

В Claude Code:

```
установи копирайтер
```

Что произойдёт автоматически:
1. Файлы скопируются в `office/agents/copywriter/`
2. Скиллы появятся в `.claude/skills/`
3. В `office/AGENTS.md` добавится строка про Копирайтера
4. В корневой `CLAUDE.md` появится `@office/agents/copywriter/core.md`
5. Director получит роутинг — будет звать Копирайтера на «напиши пост» / «лендинг» / «лонгрид» / «крео»
6. На экране появится короткое сообщение что делать дальше

Руками править ничего не нужно.

## Как пользоваться

### Шаг 1 — собери свой голос (один раз)

```
собери мой голос
```

Копирайтер попросит 5-15 твоих текстов (посты, длинные сообщения, расшифровки голосовых, кейсы). За один заход соберёт твой камертон.

**Без этого голоса копирайтер писать отказывается** — иначе будет AI-слоп.

### Шаг 2 — пиши что нужно

```
напиши пост про X
сделай лендинг для Y
напиши лонгрид-прогрев на тему Z
придумай 3 креатива для рекламы продукта W
серию из 10 постов про U
пост-история про моего клиента V
```

Копирайтер пишет в твоём голосе + подбирает подходящий регистр.

### Шаг 3 — после текста выбери одно из 5

| Цифра | Что делает |
|-------|-----------|
| **1** | Почистить от AI-слопа |
| **2** | Докрутить по смыслам (5 линз — аватар, жирность, глубина, обогащение, сегментация) |
| **3** | Пересобрать с нуля под другим углом (через боль / результат / провокацию) |
| **4** | Переписать в другом регистре (один или сразу несколько для сравнения) |
| **5** | Сохранить как готовое в `hub/content/` |

После каждой опции 1-4 — снова та же развилка. Жми пока не скажешь «5».

### Опция — собрать свой регистр под нишу

Если 5 стартовых регистров не покрывают задачу — свой регистр можно будет собрать в версии 1.1.0 (см. `CHANGELOG.md` → Roadmap). Пока — пользуйся стартовыми пятью.

## Обновление

```bash
cd _agent-packs/copywriter
git pull
```

В Claude Code:

```
установи копирайтер
```

**Твои данные не затрутся:**
- `voice.md` (собранный голос) — остаётся
- `voice-*.md` (включая твои собранные регистры) — остаются
- `memory.md` / `failures.md` / `overrides.md` — остаются

Обновится только ядро: логика копирайтера, универсальная механика, скиллы.

---

## Если что-то не работает

- **«не могу установить»** — проверь что у тебя в офисе есть команда `/install-agent` (приходит вместе с `client-office-template`). Если её нет — `git clone` всё равно сработал, дальше можно поставить руками по `install.md`.
- **«копирайтер пишет в нейтральном AI-стиле»** — голос не собран. Скажи «собери мой голос», кинь свои тексты.
- **«не находит мою аудиторию»** — установлен ли Маркетолог (Алекс)? Если нет, копирайтер спросит ЦА у тебя в чате.
- **«какой регистр выбрать»** — скажи «покажи регистры» или нажми «4» в развилке после текста — копирайтер сам предложит.
